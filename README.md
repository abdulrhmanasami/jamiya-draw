# قرعة جمعية العيلة

صفحة بتتحقق من ترتيب القرعة: https://abdulrhmanasami.github.io/jamiya-draw/

الطريقة: كل اسم رقم من 1 لـ N. لكل رقم بينحسب SHA-256 للنص `<hash البلوك>:<الرقم>`، ومنرتب من الأصغر للأكبر. الأول بيقبض أول شهر (11/2026)، والتاني الشهر اللي بعده، وهيك.

نفس الحساب بـ Python: `python3 draw.py <hash> <N>`
